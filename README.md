# 📘 Data Structures & Algorithms Collection

This repository contains well-structured implementations of core Data Structures and Algorithms using C++.

## 📂 Topics Covered

* Searching (Linear Search, Binary Search)
* Sorting (Bubble Sort, Selection Sort, Merge Sort, Quick Sort, Bucket Sort)
* Greedy Algorithms (Fractional Knapsack, Huffman Coding)
* Graph Algorithms (Dijkstra, Floyd Warshall, Prim's, Kruskal's)
* Dynamic Programming (0/1 Knapsack)

## 🛠 Language

* C++

## 🎯 Purpose

To organize lab assignments and practice problems into a clean, structured repository for easy understanding and revision.
