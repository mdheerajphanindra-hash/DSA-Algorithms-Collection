# ⚡ Divide and Conquer

This folder contains implementations of divide and conquer algorithms.

## 📂 Files Included

* max_min.cpp — Find minimum and maximum elements
* maximum_subarray.cpp — Maximum subarray sum problem
* strassen_matrix.cpp — Strassen’s matrix multiplication

## 📌 Description

Divide and conquer algorithms solve problems by breaking them into smaller subproblems, solving each independently, and combining the results.
