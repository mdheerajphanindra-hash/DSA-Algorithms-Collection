# 📦 Data Structures

This folder contains implementations of fundamental data structures.

## 📂 Files Included

* stack.cpp — Stack implementation using linked list

## 📌 Description

Data structures are used to store and organize data efficiently for different operations such as insertion, deletion, and searching.
